Origens de questões

Cada linha é uma origem. Com uma prova, as faixas escolhem os números (ex.: 1-10, 32-46, 71-100; em branco = prova toda). Sem prova, os filtros de disciplina/assunto/banca/ano valem para todas as provas. Os campos de uma linha se combinam. Várias linhas juntam questões de várias provas; uma questão repetida entra só uma vez.

Questões fora do escopo deste bloco (continuam no banco). 10-17 = esses números em qualquer prova do bloco; 42:7 = questão 7 só da prova 42 (o número à esquerda é o id da prova na lista acima); #315 = questão pelo id.
