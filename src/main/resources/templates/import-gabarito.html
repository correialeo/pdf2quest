Importar Gabarito (PDF)

Use esta tela quando o gabarito estiver em um PDF separado da prova, contendo (possivelmente) vários perfis/tipos de prova. Informe o título exato do perfil desejado (ex.: "ATI - DESENVOLVIMENTO DE SOFTWARE – PROVA TIPO 1") e selecione a importação de prova correspondente para vincular as respostas às questões já cadastradas.
