Sem PDF: traga questões de uma planilha ou de um arquivo JSON. Antes de gravar, você vê uma prévia e os problemas encontrados.

Planilha (CSV)

Do Excel, LibreOffice ou Google Planilhas: use Arquivo › Salvar como / Baixar › CSV. No passo seguinte você diz qual coluna é o enunciado, as alternativas, a resposta etc.

Arquivo JSON

Formato próprio do PDF2Questão, para bancos de questões gerados por outros programas ou compartilhados entre pessoas. Guarda tudo: explicação, assuntos, tags, texto base e referências.
